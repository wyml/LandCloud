## M0 项目初始化与基础设施

**目标**：可运行的空骨架 + CI/部署通路。

任务：

- Next.js 16+（App Router、TypeScript）脚手架；目录结构按 PRD §5.2 落地。
- HeroUI 集成（Provider、主题、暗色模式开关预留）。
- ESLint + Prettier + TypeScript strict；`npm run lint` / `typecheck` 通过。
- Supabase 项目创建；本地 `.env.example`（Supabase URL/anon/service_role、S3 凭证、ADMIN_EMAIL、站点域名）。
- Supabase 客户端封装：`browser` / `server` / `admin(service_role)` 三端。
- Vercel 项目接入 Git 仓库，预览部署跑通。

**验收标准**：

- `npm run dev` / `build` / `lint` 全绿。
- Vercel 预览环境可访问占位首页。
- `.env.example` 覆盖所有后续环境变量。

## M1 数据层与管理员认证

**目标**：数据库就绪，管理员可登录。

任务：

- Supabase Migration（SQL 脚本纳入仓库）：PRD §5.3 全部 8 张表 + 索引 + 触发器（`updated_at`）。
- RLS 策略：默认拒绝；基于 JWT email 与 `ADMIN_EMAIL` 匹配的 `is_admin()` 函数授予读写；公开数据只读策略。
- `/admin/login` 登录页（HeroUI 表单）；登录/登出流程。
- 管理员守卫：middleware + 服务端双重校验（非 ADMIN_EMAIL 登录后可访问前台但后台 403）。
- `site_settings` 初始化种子数据（站点名等默认值）。

**验收标准**：

- 匿名客户端直连数据库无法读写任何非公开数据（用 Supabase SQL Editor 模拟验证）。
- 错误邮箱登录后台返回 403；正确邮箱可进入后台占位页。

## M2 S3 接入与上传处理流水线

**目标**：图片可直传 S3 并自动完成处理。

任务：

- S3 客户端封装（`@aws-sdk/client-s3` / `s3-request-presigner`），兼容 R2 等（endpoint 可配）。
- `/api/upload/presign`：管理员校验、MIME 白名单、10 分钟有效、Content-Length ≤ 50MB。
- `/api/upload/complete`：校验对象存在与大小、SHA-256 计算去重、写入 `images`（pending）、异步触发处理。
- 处理流水线（sharp + exif-reader）：
  - EXIF 提取 → `exif` jsonb + `gps_lat/gps_lng` + `taken_at` 回填。
  - 变体生成：`display.webp`(2560px/q80)、`thumb_lg/md/sm`；GIF/SVG 特殊分支。
  - 状态机 pending→processing→done/failed；失败重试接口 `/api/upload/reprocess`。
- 路径规范 `images/{yyyy}/{mm}/{id}/{variant}.{ext}` 与变体元数据入库。
- **实况照片（Live Photos）支持**：
  - 识别 HEIC/HEIF 格式中的实况照片（包含静态图 + MOV 视频）。
  - 上传时自动提取静态帧和关联视频，存储为 `image` + `live_photo_video` 两个对象。
  - 前端展示时支持实况照片标识和播放按钮（点击播放短视频）。
  - 数据库 `images` 表增加 `is_live_photo`、`live_photo_video_key` 字段。

**验收标准**：

- 浏览器直传 50MB JPG 成功，全流程无人工干预产出 5 个变体与 EXIF。
- 重复上传被拦截并返回已有记录。
- 模拟处理失败后可重试成功；非图片文件被 MIME/魔数校验拒绝。
- 上传 HEIC 格式实况照片可正确分离静态图和视频，前台展示带播放标识。

## M3 图片管理后台

**目标**：图片全生命周期管理 + 外链获取。

任务：

- 图片列表页：表格/网格双视图、分页；筛选（相册/标签/可见性/时间）+ 关键词搜索 + 排序。
- 上传入口：拖拽批量（≤50 张）、进度展示、指定相册/标签/可见性；处理中/失败状态徽标与重试按钮。
- 编辑抽屉：标题、描述、标签（多选可新建）、可见性、所属相册、拍摄时间、设为封面。
- 批量操作栏：多选 → 移动相册 / 打标签 / 改可见性 / 删除（二次确认，级联删除 S3 变体）。
- 外链面板：直链/代理链接 × 变体切换，Markdown/HTML/URL/BBCode 复制。
- 标签管理页：CRUD + 图片计数。

**验收标准**：

- 上传 20 张混合尺寸图片，列表、筛选、编辑、批量操作全部可用。
- 删除图片后 S3 中无任何残留变体。
- 私密图片外链面板不出现直链。

## M4 相册与标签管理

**目标**：相册管理完整闭环。

任务：

- 相册列表：排序权重调整、可见性徽标、封面缩略、图片数。
- 相册编辑页：名称/简介/可见性/封面选择（从相册内图片选或默认最新）。
- 相册内图片管理：添加（从图片库多选）、移除、手动拖拽排序（写 `album_images.sort_order`）。
- 删除相册二次确认（仅解除关联，不删图片）。
- 标签与相册联动校验（标签页已在 M3 完成，此处补删除标签的关联清理验证）。

**验收标准**：

- 创建 3 种可见性相册各一，前台表现符合预期（private/password 不在公开列表出现）。
- 拖拽排序刷新后保持；同一图片可出现在两个相册。

## M5 访客展示站

**目标**：对外相册展示完整可用。

任务：

- 布局与导航（站点名/Logo 读 `site_settings`）；响应式适配移动端。
- 首页：公开相册卡片（封面、简介、图片数、浏览量）。
- 相册列表页 + 详情页：网格缩略图、无限滚动分页。
- 图片详情页：WebP 展示、原图入口、EXIF 面板、标签、所属相册、上下张切换、浏览量上报。
- 标签聚合页 / 标签详情页。
- 搜索页：图片+相册分组结果（标题/文件名/描述/标签/年份）。
- 访问计数上报接口 `/api/stats`（sessionStorage 去重）。
- SEO 基础：metadata、sitemap（仅公开内容）、robots.txt（屏蔽 /admin、/f、/s）。

**验收标准**：

- Lighthouse 移动端首页性能 ≥ 90（预览环境）。
- 私密相册直接访问 URL 返回 404；搜索引擎不会索引私密内容。

## M6 分享、外链与代理（可与 M5 并行）

**目标**：密码分享与图片代理链路闭环。

任务：

- 分享管理页：创建（目标、密码、有效期选项）、列表、撤销。
- `/s/[share_id]` 密码页：校验（bcrypt + 过期 + 撤销）、限频（5 次/分钟/IP）、成功后签发 24h HMAC cookie。
- 分享通过后渲染目标相册/单图（复用 M5 组件）。
- `/f/[id]/[variant]` 代理路由：按可见性分流（public 直出 + 强缓存 / private 校验登录 / password 校验分享 cookie），私密一律 404 语义。
- 过期分享自动失效（查询时校验，无需定时任务）。

**验收标准**：

- 密码错误 6 次触发限频；过期/撤销的分享立即不可访问。
- 未登录访问私密图代理链接返回 404；登录后正常。
- 公开图代理链接带 1 年 immutable 缓存头。

## M7 Cesium 地图轨迹

**目标**：3D 地球展示照片足迹。

任务：

- Cesium 集成（Ion 免费 token，默认世界影像；静态资源拷贝方案在 Next.js/Vercel 下跑通）。
- `/api/map/photos`：公开 + 含 GPS 图片的精简数据（id、缩略图、坐标、标题）。
- 地球页：点位聚合（按缩放级别）、聚合点点击展开缩略图弹层、单图点击跳详情。
- 统计卡片：带位置图片数、足迹位置数（粗略网格聚类，不做地名反查——PRD §8.1 默认值）。
- 移动端降级提示（小屏允许横向滚动 + 触控基本操作）。

**验收标准**：

- 上传含 GPS 照片后地图自动出现新点位。
- 缩放过程中聚合数量变化正确；弹层跳详情正常。
- 无 GPS 图片不出现在地图数据中。

## M8 统计、设置与打磨

**目标**：后台闭环 + 体验收尾。

任务：

- 仪表盘：总量卡片（图片/相册/浏览量/存储用量）、最近上传。
- 站点设置页：站点信息、外链域名前缀、默认外链类型；保存即时生效。
- 404/403/500 错误页；加载骨架屏；空状态文案。
- 全站文案中文校对；HeroUI 主题统一（主色/圆角/暗色模式）。
- 性能复查：图片列表懒加载、Cesium 按需加载（路由级代码分割，避免拖慢首页）。

**验收标准**：

- 设置修改后前台首页即时反映新站点名/Logo。
- 首页 bundle 不含 Cesium 代码（构建分析确认）。

## M9 测试加固与上线

**目标**：生产可用、安全达标。

任务：

- 测试：
  - 单元/集成：上传流水线、分享校验、RLS 策略、代理路由权限分支。
  - E2E（Playwright）：登录→上传→建相册→前台访问→分享密码→外链 6 条关键路径。
- 安全清单核查：RLS 全覆盖、service_role 未泄露到客户端、预签名限制、限频生效、MIME 魔数校验、私密内容 404 语义。
- 生产环境：Vercel 正式域名、Supabase 生产项目、S3 生产桶、CORS（直传域名白名单）、备份策略（Supabase 自动备份 + S3 版本控制开启）。
- 冒烟验证 + README（部署说明、环境变量清单、备份恢复指引）。

**验收标准**：

- E2E 全绿；安全清单逐项签字。
- 生产环境完成一次真实数据全流程冒烟。

## 执行约定

1. 每个里程碑结束：`lint` + `typecheck` + 测试全绿，部署预览环境，人工验收后再进入下一阶段。
2. 数据库变更一律走 migration 文件，禁止手工改生产 schema。
3. 环境差异仅通过环境变量体现（dev/prod 各一套 Supabase + S3 桶）。
4. 风险缓冲：M2（处理超时）与 M7（Cesium 打包）为两大技术风险点，各自预留 1 天缓冲已含在估算内。
