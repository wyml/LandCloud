## 1. 项目概述

### 1.1 背景与目标

构建一个个人图床 + 相册展示网站：

- **对外**：以相册形式向访客展示摄影作品/图片集，支持搜索、标签浏览与 3D 地图轨迹浏览。
- **对内**：站长（唯一管理员）可上传图片、管理相册与标签、获取图片外链（用于在博客、论坛等外部引用）。

### 1.2 范围

| 包含                         | 不包含                  |
| ---------------------------- | ----------------------- |
| 单管理员 + 访客模式          | 多用户注册、用户空间    |
| 公开 / 私密 / 密码三种可见性 | 评论、点赞、社交互动    |
| 图片外链（直链 + 代理链接）  | 视频 / 音频等非图片资源 |
| 缩略图、压缩、EXIF 处理      | 图片水印                |
| 标签、搜索、简单浏览统计     | 复杂数据分析、报表导出  |
| Cesium 3D 地图轨迹           | 回收站、版本历史        |

### 1.3 术语

| 术语            | 说明                                                                          |
| --------------- | ----------------------------------------------------------------------------- |
| 直链            | S3 对象的可公开访问 URL（可配置 CDN 自定义域名前缀）                          |
| 代理链接        | 形如 `/f/{id}/{variant}` 的站内链接，由应用从 S3 读取后流式返回，可做权限控制 |
| 变体（variant） | 同一图片的不同存储版本：original / display(WebP) / 缩略图                     |

## 3. 功能需求

### 3.1 访客端（展示站）

#### 3.1.1 首页

- 站点名称、Logo、简介（后台可配置）。
- 公开相册卡片列表：封面、名称、简介、图片数、浏览量；按后台设定的顺序展示。
- 顶部导航：首页 / 相册 / 标签 / 地图轨迹 / 搜索入口。

#### 3.1.2 相册列表与详情

- 相册列表页：展示全部公开相册，支持按名称模糊搜索。
- 相册详情页：
  - 相册名称、简介、图片数、浏览量。
  - 图片以响应式网格/瀑布流展示缩略图，滚动分页。
  - 仅登录管理员可见私密相册（后台预览视角）；访客访问私密相册返回 404。

#### 3.1.3 图片详情

- 大图展示（WebP 压缩版，自适应屏幕；可查看原图链接）。
- 展示信息：标题、描述、标签、拍摄时间、浏览量、所属相册。
- EXIF 信息面板：相机、镜头、焦距、光圈、快门、ISO、拍摄时间（有则展示）。
- 若含 GPS 信息：展示拍摄地点名称（可选反向地理编码，见 §8 待确认）并提供跳转地图轨迹页定位。
- 上一张 / 下一张切换（按相册内排序）。

#### 3.1.4 密码访问

- 私密分享入口：`/s/{share_id}` 或 `/album/{id}` 带密码校验。
- 输入密码正确且未过期 → 在会话期内（默认 24h）免重复输入访问该相册/单图。
- 密码错误 / 已过期 → 对应提示；错误尝试需做简单限频（同 IP 5 次/分钟）。

#### 3.1.5 标签

- 标签聚合页：展示全部标签（含图片计数）。
- 标签详情页：该标签下的图片网格，滚动分页。

#### 3.1.6 搜索

- 全站搜索页：按关键词搜索图片与相册。
- 匹配范围：标题、文件名、描述、标签名、拍摄时间（年份）。
- 结果分组展示（相册 / 图片），仅命中公开内容。

#### 3.1.7 地图轨迹（Cesium 3D 地球）

- 独立页面 `/map`，加载 Cesium 3D 地球。
- 将所有含 GPS 坐标的**公开**图片聚合打点；点聚合（cluster）按缩放级别显示数量。
- 点击聚合点展开 → 弹出该位置图片缩略图列表 → 点击缩略图跳转图片详情。
- 侧边/顶部展示统计：足迹国家/城市数量、带位置图片数（基于坐标反查，见 §8 待确认）。

### 3.2 管理后台

#### 3.2.1 登录

- `/admin/login`：邮箱 + 密码（Supabase Auth）。
- 仅 `ADMIN_EMAIL` 对应账号可进入后台；其余账号登录后访问后台返回 403。
- 无注册入口。

#### 3.2.2 仪表盘

- 概览卡片：图片总数、相册总数、总浏览量、存储用量（所有图片字节数合计）。
- 最近上传列表（最近 10 张）。

#### 3.2.3 图片管理

- **上传**
  - 拖拽 / 点击选择批量上传，单次最多 50 张，单张 ≤ 50MB。
  - 支持格式：JPG / PNG / WebP / GIF / AVIF / SVG。
  - 上传时可指定：目标相册（可多个）、标签、可见性（默认跟随相册）、拍摄时间修正。
  - 采用 S3 预签名直传（浏览器 → S3），上传完成后服务端异步执行处理流水线（§5.4）；处理中的图片显示状态标记，处理失败可一键重试。
  - 按内容哈希（SHA-256）去重：重复上传提示已存在。
- **列表与筛选**
  - 表格/网格双视图；按相册、标签、可见性、上传时间筛选；关键词搜索。
  - 排序：上传时间、拍摄时间、浏览量。
- **编辑**
  - 修改标题、描述、标签、可见性、所属相册、拍摄时间。
  - 设为某相册封面。
- **批量操作**
  - 多选后：批量移动相册、批量打标签、批量改可见性、批量删除（删除同时删除 S3 所有变体，需二次确认）。
- **外链获取**（详见 §3.3）

#### 3.2.4 相册管理

- 相册 CRUD：名称、简介、封面（默认取最新图片，可手动指定）、排序权重。
- 可见性三态：
  - `public`：公开展示。
  - `private`：仅管理员可见。
  - `password`：不在公开列表展示，通过分享链接 + 密码访问。
- 单层结构，不支持子相册；一张图片可属于多个相册。
- 相册内图片排序：默认按拍摄时间倒序，支持手动拖拽调整。

#### 3.2.5 标签管理

- 标签 CRUD（删除标签自动解除与图片的关联）。
- 标签列表展示图片计数。

#### 3.2.6 分享管理

- 为相册或单图创建密码分享：自定义密码、有效期（永久 / 1 天 / 7 天 / 30 天 / 自定义日期）。
- 分享列表：链接、目标、有效期状态、访问次数；可提前撤销。
- 分享页复用访客端密码访问流程。

#### 3.2.7 浏览统计

- 简单计数：图片浏览量 PV、相册浏览量 PV、分享访问次数。
- 后台图片列表/相册列表展示浏览量；仪表盘展示总量与最近上传。
- 计数方式：详情页加载时异步 +1（同一浏览器会话内对同一图片仅计 1 次，sessionStorage 去重）。

#### 3.2.8 站点设置

- 站点名称、Logo、简介、页脚文案。
- 外链配置：直链域名前缀（S3/CDN 公网地址）、是否默认启用直链。
- 设置以键值表存储，后台表单编辑。

### 3.3 图片外链

在图片详情（管理端）提供外链面板：

| 类型     | 形式                                       | 说明                                                 |
| -------- | ------------------------------------------ | ---------------------------------------------------- |
| 直链     | `{S3_PUBLIC_BASE}/images/.../display.webp` | 公开图片可用；可切换 original / display / 缩略图变体 |
| 代理链接 | `https://站点/f/{id}/{variant}`            | 受权限控制（私密图仅登录后可见），流量经过站点       |
| 一键复制 | Markdown / HTML / 纯 URL / BBCode          | 四种格式复制到剪贴板                                 |

- 私密图片不生成直链，仅提供代理链接（需登录态）。
- 密码分享的图片：代理链接跳转密码校验页。

### 3.4 浏览统计（汇总）

见 §3.2.7。不做趋势图与排行榜（列为后续迭代）。

### 5.3 数据模型（Supabase Postgres）

| 表              | 关键字段                                                                                                                                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `profiles`      | id(FK auth.users), email, display_name, avatar_url                                                                                                                                                                     |
| `albums`        | id, name, description, cover_image_id, visibility(public/private/password), sort_order, view_count, created_at, updated_at                                                                                             |
| `images`        | id, title, description, original_name, mime, size_bytes, width, height, sha256, s3_key, visibility, taken_at, exif(jsonb), gps_lat, gps_lng, view_count, processing_status(pending/processing/done/failed), created_at |
| `album_images`  | album_id, image_id, sort_order（多对多）                                                                                                                                                                               |
| `tags`          | id, name                                                                                                                                                                                                               |
| `image_tags`    | image_id, tag_id                                                                                                                                                                                                       |
| `shares`        | id, target_type(album/image), target_id, password_hash, expires_at(null=永久), view_count, revoked, created_at                                                                                                         |
| `site_settings` | key, value(jsonb)                                                                                                                                                                                                      |

说明：

- 相册/图片密码可见性：`password` 类型统一走 `shares` 表（相册表的 visibility 标记是否加密展示）。
- EXIF 全量存 jsonb，常用字段（相机、光圈等）冗余列可选，MVP 阶段只存 jsonb + gps 冗余列。
- 浏览量为简单计数列，不建流水表。

### 5.4 图片处理流水线

上传完成回调后异步执行（Node Runtime）：

1. 从 S3 拉取原图（或使用流式处理）。
2. EXIF 读取：exiftool 等价能力由 sharp metadata + exif-reader 提供；写入 `images.exif`、冗余 GPS。
3. 生成变体并写回 S3：
   - `display.webp`：长边 2560px、质量 80 的 WebP（用于详情页展示）。
   - `thumb_lg.webp`（800px）/ `thumb_md.webp`（480px）/ `thumb_sm.webp`（160px）。
   - GIF / SVG 不生成 WebP 变体，仅生成静态缩略图（GIF 取首帧）。
4. 更新 `processing_status = done`；失败置 `failed` 并保留重试入口。

**S3 路径规范**：`images/{yyyy}/{mm}/{image_id}/{variant}.{ext}`。

**风险与对策**：Vercel Hobby 函数时长上限 10s，大文件处理可能超时 → 处理任务拆分为"单图单任务 + 完成回调触发"，并可在 Pro 计划放宽时长；MVP 先以 50MB 内常规照片为基准验证。

### 5.5 关键流程

**上传流程**

```
浏览器请求预签名 PUT(校验管理员) → 浏览器直传 S3 → 浏览器回调 /api/upload/complete
→ 服务端校验对象存在 → 写 images 记录(pending) → 触发处理任务 → 完成后置 done
```

**代理链接流程**

```
GET /f/{id}/{variant} → 查可见性
  public → 流式返回 S3 对象（Cache-Control: public, max-age=1年, immutable）
  private → 校验管理员登录态，否则 404
  password → 校验分享会话 cookie，否则 302 到密码页
```

**密码分享流程**

```
/s/{share_id} → 输入密码 → POST 校验(bcrypt + 有效期 + 撤销状态)
→ 成功后签发短期 HTTP-only cookie（含 share_id + HMAC）→ 会话期 24h 免重复输入
```

## 7. 安全要点

- Supabase RLS：所有表默认拒绝，管理员（以 `ADMIN_EMAIL` 匹配的 JWT）拥有写权限；访客仅可读公开数据的公开列。
- 服务端 SDK 使用 `service_role` 密钥仅限 Route Handler 内部，绝不下发到客户端。
- 密码分享：bcrypt 哈希；错误限频；过期/撤销立即失效。
- 预签名 URL：仅管理员可获取，10 分钟过期，限定 key 前缀与 Content-Length。
- 代理接口对私密内容一律 404（不暴露存在性）。
- 上传校验：MIME 白名单 + 魔数校验（服务端回调时校验），拒绝可执行文件伪装。

## 9. 里程碑规划

（本文档确认后另行输出里程碑与任务分解。）
